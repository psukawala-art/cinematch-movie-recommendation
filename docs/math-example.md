# Linear Algebra Worked Example

User A: [5, 4, 1]
User B: [4, 5, 1]

Dot product = 5×4 + 4×5 + 1×1 = 41
Magnitude A = sqrt(25 + 16 + 1) = sqrt(42)
Magnitude B = sqrt(16 + 25 + 1) = sqrt(42)
Cosine similarity = 41 / (sqrt(42) × sqrt(42)) = 41/42 ≈ 0.976

The vectors are very similar. For real data, compare only movies both users rated; an unrated movie is unknown, not a zero rating.
